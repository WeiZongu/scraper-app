# サイト別スクレイピングツール

サイトごとにCSSセレクタ設定（JSON）を保存しておき、GUIから選んで実行するだけで
データ収集 → プレビュー → Excel帳票出力（集計・グラフ付き）まで行えるツールです。

JavaScriptで動的にコンテンツを描画するサイト（SPA等）にも対応するため、
収集エンジンには [Playwright](https://playwright.dev/python/) を使用しています。

## セットアップ

```bash
cd scraper_app
python -m venv venv
source venv/bin/activate   # Windowsは venv\Scripts\activate

pip install -r requirements.txt
playwright install chromium   # 初回のみ。Chromiumブラウザ本体をダウンロードします
```

## iPhoneだけで使う（クラウドにデプロイ）

このアプリはPlaywright（ブラウザ自動操作）を使うため、iPhone単体では動作しません。
自分のPCも使わずに済むように、クラウド上に一度だけデプロイしておき、
以降はiPhoneのSafariだけで使う方法です。

- **完全無料・超過時は自動課金されず単に使えなくなる運用にしたい場合** →
  [`ORACLE_DEPLOY.md`](./ORACLE_DEPLOY.md)（Oracle Cloud 永久無料枠、詳細手順あり）
- **多少の月額費用でもよく、手軽さ優先の場合** → 下記のRender手順

### Renderでのデプロイ（参考・有料枠推奨）
無料枠もありますが、スリープや再起動でのデータ消失があり、超過時は自動課金される
アカウント形態です。手軽さ重視ならこちら、課金リスクを避けたい場合は上記Oracle手順を
使ってください。

1. このフォルダの中身をGitHubリポジトリにpush
2. Renderにログイン →「New +」→「Web Service」→ 先ほどのリポジトリを選択
3. **Environment** は「Docker」を選択（同梱の `Dockerfile` が自動で使われます）
4. **Instance Type** は無料枠（Free）でOK
5. 環境変数に `APP_PASSWORD` を設定することを強く推奨します（例: `APP_PASSWORD=好きな文字列`）。
   これを設定しないと、URLを知っている誰でもアプリを操作できてしまいます。
6. 「Create Web Service」でデプロイ開始（初回ビルドはブラウザ同梱のため数分かかります）

デプロイが終わると `https://xxxxx.onrender.com` のようなURLが発行されます。
Safariでこれを開き、共有メニュー→「ホーム画面に追加」でアプリのように起動できます。

### 無料枠の制約と対策
- **一定時間アクセスがないとスリープします。** 次回アクセス時に数十秒〜1分ほど起動待ちが発生します。
- **再起動・再デプロイのたびに保存データが消えます（ディスクが一時的なため）。**
  「サイト一覧」タブの **「設定をバックアップ」** で保存済みサイト設定をJSONファイルとしてダウンロードし、
  iPhoneのFilesアプリ等に保管しておいてください。消えてしまった場合は **「設定を復元」** から
  そのJSONファイルを選ぶだけで元に戻せます。
- 出力したExcel帳票も同様に一時保存です。生成後はその場でダウンロードして保存してください。

### Render以外の選択肢
[Railway](https://railway.app/) や [Fly.io](https://fly.io/) も同様にDockerfileから無料枠デプロイが可能です。
手順はほぼ同じ（Dockerfileを検出させ、環境変数 `APP_PASSWORD` を設定するだけ）です。

## （参考）自宅PCから使う場合

自宅にPC/Macがあり、それを常時起動しておける場合は、クラウドを使わずに
Tailscaleでも同じことができます。

### 起動

```bash
python main.py
```

自動的にブラウザが立ち上がり、`http://localhost:8550` でGUIが表示されます
（デスクトップウィンドウではなく、ブラウザで動くWebアプリになっています）。

### Tailscale経由でiPhoneから使う

1. **PC側**
   - [Tailscale](https://tailscale.com/download) をインストールし、Googleアカウント等でログイン
   - タスクトレイのTailscaleアイコン→「This device」で `100.x.x.x` 形式のTailscale IPを確認
   - Windows セキュリティ（Defender ファイアウォール）で `python.exe`（またはポート8550）の
     受信を許可
   - `python main.py` でアプリを起動したままにしておく

2. **iPhone側**
   - App Storeから「Tailscale」アプリをインストールし、PCと同じアカウントでログイン
   - Safariで `http://<PCのTailscale IP>:8550` にアクセス
   - 共有メニュー→「ホーム画面に追加」で便利に

## 使い方

1. **「サイト一覧」タブ**の「＋ 新規サイト」から新しいサイト設定を作成、または保存済みサイトをタップして編集。
2. **「サイト設定」タブ**を入力:
   - **一覧ページURL**: `{page}` でページ番号、`{keyword}` でキーワードを差し込めます。
     例: `https://example.com/search?q={keyword}&page={page}`
   - **1件分を囲むCSSセレクタ**: 商品カードや記事1件を囲む要素（例: `.product-card`）
   - **描画完了を待つCSSセレクタ**: JSで遅れて描画される場合、その出現を待つセレクタ。
     空欄なら「1件分を囲むセレクタ」と同じものを待ちます。
   - **ページング方式**:
     - `URLのページ番号送り`: `{page}` を1,2,3...と増やしながら取得
     - `「次へ」ボタンをクリック`: ボタンのセレクタを指定してクリックしながら取得
     - `無限スクロール`: 下にスクロールしながら新規要素の出現を待って取得
     - `単一ページのみ`: 1ページだけ取得
3. **取得項目**を追加:
   - **列名**: 帳票の列見出しになります
   - **相対CSSセレクタ**: 「1件分の要素」からの相対セレクタ
   - **取得方法**: `text`（テキスト）/ `html`（内部HTML）/ 属性名（`href`, `src` など）
   - **数値として集計**: チェックすると数値化して集計・グラフの対象になります
     （「¥1,980」「1,980円」のような文字列からも数値部分を自動抽出します）
4. 「設定を保存」でサイト設定をJSONとして保存（次回以降、「サイト一覧」タブから呼び出し可能）。
5. **「実行・結果」タブ**でキーワード・開始ページを指定して「実行」。ログとプレビュー（最大200件）が表示されます。
6. 「帳票出力(Excel)」でExcelファイルを生成し、表示されたリンクからダウンロードします。
   - `Data`シート: 取得した全データ（罫線・ヘッダー装飾・オートフィルタ付き）
   - `Summary`シート: 総件数、数値項目ごとの件数・合計・平均・最大・最小（数式で計算、
     元データを変更すれば自動的に再計算されます）＋ 先頭の数値項目の分布を示す棒グラフ

## サンプル設定

`site_configs/sample.json` に、動作確認用のサンプル設定
（[books.toscrape.com](https://books.toscrape.com) というスクレイピング練習用サイト）
を同梱しています。起動後、「サイト一覧」タブの「サンプル(book.toscrape.com)」から実行してみてください。

## 注意事項

- 対象サイトの利用規約・`robots.txt` を確認し、許可された範囲でご利用ください。
- サイトによって画面構成は頻繁に変わります。うまく取得できない場合は、ブラウザの
  開発者ツールで実際のCSSセレクタを確認し、設定を調整してください。
- 大量ページを高速に連続アクセスすると相手サーバーに負荷をかけるため、
  `scroll_wait_ms` や取得件数（ページ数）は控えめに設定することを推奨します。
- `headless=false`（実行時のチェックを外す）にすると、実際にブラウザが開く様子を
  確認しながらデバッグできます。ただしブラウザはPlaywrightを実行しているサーバー（クラウド or PC）上に
  開くため、iPhoneから使う場合は基本的に「headlessあり」のまま（チェックON）にしてください。
- クラウド無料枠にデプロイして公開する場合は、`APP_PASSWORD` 環境変数を必ず設定してください
  （未設定だとURLを知る誰でも操作できてしまいます）。

## ディレクトリ構成

```
scraper_app/
├── main.py                 # Flet GUI 本体（パスワード認証・バックアップ機能含む）
├── Dockerfile               # Render/Railway等へのデプロイ用
├── .dockerignore
├── requirements.txt
├── scraper/
│   ├── config.py            # サイト設定の読み書き
│   ├── engine.py             # Playwrightによる収集処理
│   └── exporter.py           # Excel帳票出力
├── site_configs/            # サイトごとの設定(JSON)保存先
│   └── sample.json
└── assets/                  # Fletが配信する静的ファイル置き場
    ├── output/               # 出力されたExcelファイル（ダウンロードリンクの実体）
    └── downloads/            # サイト設定バックアップJSONの置き場
```
