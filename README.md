# キーワード検索・抽出ツール

CSSセレクタの指定は不要です。**検索キーワード**でWebを検索し、見つかったページの中から
**抽出キーワード**を含むテキストの塊をまるごと拾い集める、キーワードだけで使えるツールです。
設定（検索キーワード・抽出キーワード）をJSONで保存しておき、GUIから選んで実行するだけで
データ収集 → プレビュー → Excel帳票出力まで行えます。

JavaScriptで動的にコンテンツを描画するサイト（SPA等）にも対応するため、
収集エンジンには [Playwright](https://playwright.dev/python/) を使用しています。
Web検索には [Brave Search API](https://api-dashboard.search.brave.com/) を使用しています
（検索エンジンのページを直接スクレイピングする方式は、bot検知やHTML構造の変化で
不安定になりやすいため、正式なAPIを使う方式にしています）。

## 事前準備: Brave Search APIキーの取得（無料枠あり）

1. https://api-dashboard.search.brave.com/ にアクセスし、アカウントを作成してログイン
2. 「Free AI」など無料枠のプランを選択してサブスクリプションを作成
   （※サインアップ条件・無料枠の内容は変更される場合があるため、登録時の画面で最新の内容を確認してください）
3. ダッシュボードでAPIキーを発行し、控えておく（`BSAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` のような文字列）
4. このAPIキーを、後述の環境変数 `BRAVE_SEARCH_API_KEY` に設定します

## セットアップ

```bash
cd scraper_app
python -m venv venv
source venv/bin/activate   # Windowsは venv\Scripts\activate

pip install -r requirements.txt
playwright install chromium   # 初回のみ。Chromiumブラウザ本体をダウンロードします
```

## iPhoneだけで使う（クラウドにデプロイ）

このアプリはPlaywright（ブラウザ自動操作）を使うため、iPhone単体では動作しません。
自分のPCも使わずに済むように、クラウド上に一度だけデプロイしておき、
以降はiPhoneのSafariだけで使う方法です。

- **完全無料・超過時は自動課金されず単に使えなくなる運用にしたい場合** →
  [`ORACLE_DEPLOY.md`](./ORACLE_DEPLOY.md)（Oracle Cloud 永久無料枠、詳細手順あり）
- **多少の月額費用でもよく、手軽さ優先の場合** → 下記のRender手順

### Renderでのデプロイ（参考・有料枠推奨）
無料枠もありますが、スリープや再起動でのデータ消失があり、超過時は自動課金される
アカウント形態です。手軽さ重視ならこちら、課金リスクを避けたい場合は上記Oracle手順を
使ってください。

1. このフォルダの中身をGitHubリポジトリにpush
2. Renderにログイン →「New +」→「Web Service」→ 先ほどのリポジトリを選択
3. **Environment** は「Docker」を選択（同梱の `Dockerfile` が自動で使われます）
4. **Instance Type** は無料枠（Free）でOK
5. 環境変数を設定します:
   - `BRAVE_SEARCH_API_KEY`: 上記「事前準備」で取得したAPIキー（**必須**。無いと検索できません）
   - `APP_PASSWORD`: 好きな文字列（強く推奨）。これを設定しないと、URLを知っている
     誰でもアプリを操作できてしまいます。
6. 「Create Web Service」でデプロイ開始（初回ビルドはブラウザ同梱のため数分かかります）

デプロイが終わると `https://xxxxx.onrender.com` のようなURLが発行されます。
Safariでこれを開き、共有メニュー→「ホーム画面に追加」でアプリのように起動できます。

### 無料枠の制約と対策
- **一定時間アクセスがないとスリープします。** 次回アクセス時に数十秒〜1分ほど起動待ちが発生します。
- **再起動・再デプロイのたびに保存データが消えます（ディスクが一時的なため）。**
  「サイト一覧」タブの **「設定をバックアップ」** で保存済みサイト設定をJSONファイルとしてダウンロードし、
  iPhoneのFilesアプリ等に保管しておいてください。消えてしまった場合は **「設定を復元」** から
  そのJSONファイルを選ぶだけで元に戻せます。
- 出力したExcel帳票も同様に一時保存です。生成後はその場でダウンロードして保存してください。

### Render以外の選択肢
[Railway](https://railway.app/) や [Fly.io](https://fly.io/) も同様にDockerfileから無料枠デプロイが可能です。
手順はほぼ同じ（Dockerfileを検出させ、環境変数 `BRAVE_SEARCH_API_KEY` と `APP_PASSWORD` を
設定するだけ）です。

## （参考）自宅PCから使う場合

自宅にPC/Macがあり、それを常時起動しておける場合は、クラウドを使わずに
Tailscaleでも同じことができます。

### 起動

```bash
export BRAVE_SEARCH_API_KEY=取得したAPIキー   # Windowsは set BRAVE_SEARCH_API_KEY=...
python main.py
```

自動的にブラウザが立ち上がり、`http://localhost:8550` でGUIが表示されます
（デスクトップウィンドウではなく、ブラウザで動くWebアプリになっています）。

### Tailscale経由でiPhoneから使う

1. **PC側**
   - [Tailscale](https://tailscale.com/download) をインストールし、Googleアカウント等でログイン
   - タスクトレイのTailscaleアイコン→「This device」で `100.x.x.x` 形式のTailscale IPを確認
   - Windows セキュリティ（Defender ファイアウォール）で `python.exe`（またはポート8550）の
     受信を許可
   - `python main.py` でアプリを起動したままにしておく

2. **iPhone側**
   - App Storeから「Tailscale」アプリをインストールし、PCと同じアカウントでログイン
   - Safariで `http://<PCのTailscale IP>:8550` にアクセス
   - 共有メニュー→「ホーム画面に追加」で便利に

## 使い方

1. **「検索設定一覧」タブ**の「＋ 新規設定」から新しい設定を作成、または保存済み設定をタップして編集。
2. **「検索設定」タブ**を入力:
   - **設定名**: 一覧に表示される名前（任意の名前でOK）
   - **検索キーワード**: Webを検索するためのキーワード（例: `東京 ラーメン 新宿`）
   - **抽出キーワード**: ページの中から探したい語句をカンマ区切りで複数指定
     （例: `営業時間, 定休日, 住所`）。このキーワードを含むテキストの塊をまるごと抜き出します。
     CSSセレクタの知識は不要です。
3. 「設定を保存」で検索設定をJSONとして保存（次回以降、「検索設定一覧」タブから呼び出し可能）。
4. **「実行・結果」タブ**で「実行」。検索結果に見つかったページを片っ端から開いて抽出します
   （開くページ数の上限はありません。検索結果が尽きるまで自動的に続けます）。
   検索 → 各ページを開いて抽出、の様子がログとプレビュー（最大200件）に表示されます。
5. 「帳票出力(Excel)」でExcelファイルを生成し、表示されたリンクからダウンロードします。
   - キーワード・抜粋テキスト・画像・動画URL・ページタイトル・URL・取得日時の7列の
     シンプルな一覧です（見出し装飾・オートフィルタ・URLへのリンク付き）。
   - 画像はダウンロードしてサムネイルとしてセルに埋め込まれます
     （ダウンロードに失敗した場合はURLへのリンクとして表示されます）。
   - 動画はファイル自体はダウンロードせず、URLへのリンクとして表示されます。

### 抽出のしくみ（精度について）

CSSセレクタで正確に位置指定する方式とは違い、「抽出キーワードを含む、ある程度まとまった
テキストのかたまり」をヒューリスティック（経験則）で見つける方式です。手軽に使える一方で、
サイトのレイアウトによっては余分な文章が混ざったり、欲しい情報が拾えないことがあります。
抽出キーワードをより具体的な語句にすると精度が上がりやすいです。

画像・動画も、この「テキストの塊」と同じ場所（またはそのすぐ近くの親要素）にあるものだけを
拾います。ページ全体から無関係な画像を集めることはありません。

## サンプル設定

`site_configs/sample.json` に、動作確認用のサンプル設定を同梱しています。
起動後、「検索設定一覧」タブの「サンプル(書籍情報を探す)」から実行してみてください。

## 注意事項

- 対象サイトの利用規約・`robots.txt` を確認し、許可された範囲でご利用ください。
- Web検索には Brave Search API を利用しています。無料枠には検索回数の上限があるため、
  上限に達するとその回の検索はそこまでの結果で打ち切られます（実行ログに表示されます）。
- 開くページ数に上限を設けていないため、検索キーワードによっては非常に多くのページを
  開き続け、実行に時間がかかることがあります。様子を見ながら「実行」を止めたい場合は
  ページの再読み込みで中断できます。
- 抽出はヒューリスティック（キーワード一致）ベースのため、100%正確な抽出は保証されません。
  抽出キーワードを具体的にすることで精度が上がります。
- ブラウザは常にheadless（画面を表示しない）で実行されます。クラウド環境には画面(Xサーバー)が
  無く、headlessをオフにすると必ず失敗するためです。
- 帳票出力時に画像をダウンロードしてサムネイル化するため、画像を含む件数が多いほど
  出力に時間がかかります。
- クラウド無料枠にデプロイして公開する場合は、`APP_PASSWORD` 環境変数を必ず設定してください
  （未設定だとURLを知る誰でも操作できてしまいます）。

## ディレクトリ構成

```
scraper_app/
├── main.py                 # Flet GUI 本体（パスワード認証・バックアップ機能含む）
├── Dockerfile               # Render/Railway等へのデプロイ用
├── .dockerignore
├── requirements.txt
├── scraper/
│   ├── config.py            # 検索設定の読み書き
│   ├── engine.py             # 検索・キーワード抽出処理（Playwright）
│   └── exporter.py           # Excel帳票出力
├── site_configs/            # 検索設定(JSON)保存先
│   └── sample.json
└── assets/                  # Fletが配信する静的ファイル置き場
    ├── output/               # 出力されたExcelファイル（ダウンロードリンクの実体）
    └── downloads/            # 検索設定バックアップJSONの置き場
```
